# Identidad visual — Victoria en Cristo

## Idea central

La marca combina tres significados en un solo trazo: **V** de victoria,
**camino ascendente** y **cruz**. El brazo derecho deliberadamente más alto
evita que se lea como ancla o flecha hacia abajo y comunica avance sin recurrir
a escudos, palomas, rayos, personas generadas o paisajes religiosos genéricos.

## Sistema

- Tinta nocturna: `#07131F`.
- Oro de camino: `#E0B93D`.
- Marca maestra: `assets/branding/victoria_mark.svg`.
- Ícono maestro de tienda: `assets/branding/app_icon_master.png`.
- El ícono no lleva texto, degradados, sombras ni detalles que desaparezcan a
  20 px.
- Las fotografías de portada son contenido editorial y no forman parte del
  logotipo.

## Producción

Ejecutar `python scripts/generate_brand_icons.py` después de modificar el SVG.
El script crea de forma determinista las variantes de Android, iPhone/iPad y
Windows. El SVG fue dibujado para este proyecto con geometría propia y no
incorpora imágenes, fuentes ni marcas de terceros.
