Política de Privacidad — Victoria en Cristo

Última actualización: septiembre 2026

Esta aplicación móvil (en adelante, "la App") es operada por el equipo de Victoria en Cristo. Esta política describe qué datos recopilamos, cómo los usamos y cómo puedes ejercer tus derechos.

1. Datos que recopilamos

1.1. Cuenta y autenticación

  • Email, nombre y foto de perfil (vía Firebase Authentication, opcional con Google Sign-In).
  • ID único de usuario (UID).

1.2. Datos de uso de la app

  • Días de victoria, frecuencia de oración, plan devocional activo, configuración personal.
  • Notas bíblicas, versículos guardados, oraciones, alarmas sagradas configuradas.
  • Mensajes intercambiados con tu Compañero de Batalla (cifrados en tránsito).
  • Publicaciones anónimas en el "Muro de Batalla" (sin UID; usamos un hash con sal secreta para detectar abuso).

1.3. Datos técnicos

  • Token de Firebase Cloud Messaging para notificaciones push.
  • Reportes de errores anónimos (Firebase Crashlytics).
  • Métricas agregadas de uso (Firebase Analytics) — sin identificadores publicitarios.

1.4. Escudo de Pureza en Android

  • El Escudo usa el servicio VPN de Android únicamente para procesar consultas DNS y bloquear dominios de contenido adulto.
  • La lista de bloqueo, la decisión de bloqueo y los contadores funcionan localmente en el dispositivo.
  • Las consultas DNS permitidas se envían cifradas mediante DNS-over-HTTPS al filtro familiar de CleanBrowsing. Victoria en Cristo no recibe ni almacena el historial de dominios consultados.
  • El Escudo no inspecciona el contenido de las páginas, no redirige tráfico con fines comerciales y sólo se activa después del consentimiento explícito del usuario.

2. Cómo usamos los datos

  • Para autenticarte y proteger tu cuenta.
  • Para sincronizar tu progreso entre dispositivos.
  • Para enviarte notificaciones que tú activaste.
  • Para mejorar la app (crash reports, métricas anónimas).
  • Para moderar el Muro de Batalla y prevenir abuso.

No vendemos ni compartimos tus datos con terceros con fines comerciales.

3. Almacenamiento

  • Los datos se almacenan en Google Firebase / Cloud Firestore (us-central1).
  • Una caché local cifrada vive en tu dispositivo para uso offline.
  • Las claves de API opcionales se guardan en el almacenamiento seguro del sistema (Keychain/Keystore).

4. Compartir datos

Solo con los siguientes proveedores:

  • Google Firebase (Auth, Firestore, FCM, Crashlytics, Analytics) — Google LLC.
  • Apple (opcional, inicio de sesión en iPhone/iPad) — entrega a la App únicamente el nombre y correo que autorices; puedes ocultar tu correo.
  • Blue Letter Bible API (opcional) — solo el versículo consultado, sin datos personales.
  • CleanBrowsing Family Filter (opcional, sólo al activar el Escudo de Pureza en Android) — resuelve consultas DNS cifradas para aplicar filtrado familiar; Victoria en Cristo no recibe esas consultas.

5. Tus derechos

  • Eliminación: ve a Configuración > Cuenta > Eliminar cuenta en la app, o visita esta página.
  • Acceso / portabilidad: escríbenos para solicitar una copia de tus datos.
  • Rectificación: edita tu perfil desde la pantalla de configuración.

6. Niños

La app está pensada para mayores de 13 años. No recopilamos conscientemente datos de menores.

7. Contacto

Para consultas sobre privacidad: soporte@victoriaencristo.app
